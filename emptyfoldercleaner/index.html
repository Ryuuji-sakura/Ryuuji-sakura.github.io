空フォルダ削除とは

選んだフォルダの中から、中身が空のフォルダを探してまとめて片付ける Mac アプリです。入れ子になっていても、いちばん奥まで一度で見つけます。見つかったものは一覧に出るので、消したくないものはチェックを外してから実行できます。

必要な環境

macOS 14（Sonoma）以降。

よくある質問

「削除できるものは見つかりませんでした」と出る
そのフォルダ以下のどこかに実ファイルが1つでもあると、上のフォルダは空とみなしません。また、隠しフォルダ（.git など）と、パッケージ（.app、写真ライブラリ、.xcodeproj など）の中には入りません。中に空のフォルダがあっても触らない作りです。中身を壊さないための仕様です。

Finder で見ると空なのに、対象にならない
目に見えない .DS_Store というファイルが入っていることがあります。「Finderの設定ファイルだけが残っているフォルダも、空として削除する」がオンになっているか確認してください（既定はオン）。それでも対象にならない場合は、さらに奥の階層に実ファイルが残っています。

「Finderの設定ファイル」とは何ですか
.DS_Store という名前の、目に見えないファイルです。フォルダを開いたときの並び順、ウィンドウの大きさ、アイコンの位置を覚えておくために Finder が自動で作ります。消してもフォルダ名や中のファイルには影響しません。

消したはずの設定ファイルが戻ってくる
次にそのフォルダを Finder で開くと、Finder が自動的に作り直します。削除に失敗したわけではありません。

選んだフォルダ自体は消えますか
消えません。消えるのはその中にある空のフォルダだけです。

間違えて消してしまった
既定ではゴミ箱に入ります。ゴミ箱で右クリックして「戻す」を選ぶと、元の場所に戻ります。入れ子になった空フォルダはまとめて1項目としてゴミ箱に入るので、元の形のまま戻ります。

「完全に削除する」と何が違いますか
「削除したものをゴミ箱に入れる」のチェックを外すと完全削除になり、ゴミ箱を経由せず、元に戻せません。このときはボタンが赤くなり、確認画面でも Enter キーでは実行できないようにしてあります。必ずクリックが必要です。

大きなフォルダを選ぶと時間がかかる
ホームフォルダのような大きな場所は、調べるのに時間がかかります。進み具合は「スキャン中... ○○項目」と件数で表示されます。やめたいときは「中止」ボタン（または ⌘.）を押してください。

中止すると、そこまでの結果は残りませんか
残しません。途中で止めた場合、まだ見ていない場所にファイルが残っている可能性があります。「空に見えただけ」のフォルダを削除候補として出すわけにはいかないので、調べかけの結果はすべて捨てます。「もう一度調べる」でやり直してください。

名前が「.DS_Store 12-34-56」のようなファイルも消えますか
NAS やクラウド同期で名前が変わったものも対象にしますが、名前だけでは判断しません。ファイルの中身を確認して、本当に Finder が作ったものだけを消します。ご自分で .DS_Store から始まる名前を付けたファイルが消えることはありません。

このアプリはどこまで見られますか
あなたが渡したフォルダの中だけです。App Sandbox に対応していて、それ以外の場所にはアクセスできません。

データはどこかに送信されますか
送信しません。このアプリは一切の通信を行いません。詳しくはプライバシーポリシーをご覧ください。

What is Empty Folder Cleaner?

A Mac app that finds empty folders inside a folder you choose and clears them out together. Nested empty folders are found all the way down in a single pass. Everything found is listed, so you can uncheck anything you want to keep before deleting. The app's interface is in Japanese.

Requirements

macOS 14 (Sonoma) or later.

FAQ

It says nothing was found
If there is even one real file anywhere beneath a folder, that folder is not treated as empty. The app also never descends into hidden folders (such as .git) or packages (.app, photo libraries, .xcodeproj), even if they contain empty folders inside — deleting those would break the enclosing app or repository.

A folder looks empty in Finder but isn't offered
It probably contains an invisible .DS_Store file. Check that the “treat folders containing only a Finder settings file as empty” option is on (it is by default). If it still isn't offered, there is a real file deeper in the tree.

What is the “Finder settings file”?
It is .DS_Store, an invisible file Finder creates to remember a folder's sort order, window size, and icon positions. Deleting it does not affect folder names or the files inside.

A deleted settings file came back
Finder recreates it the next time it displays that folder. The deletion did not fail.

Will the folder I chose be deleted?
No. Only empty folders inside it are deleted.

I deleted something by mistake
By default items go to the Trash. Right-click in the Trash and choose “Put Back” to restore them. A run of nested empty folders goes to the Trash as one item, so it comes back with its structure intact.

How is “delete permanently” different?
Turning off “move deleted items to the Trash” deletes without using the Trash, and it cannot be undone. In that mode the button turns red and the confirmation dialog deliberately has no default button, so the Return key cannot trigger it — you have to click.

Scanning a large folder takes a long time
Large locations such as your home folder take a while. Progress is shown as a live item count, and you can stop at any time with the Stop button (or ⌘.).

If I stop, do I keep the partial results?
No. When a scan is stopped part way, there may be files in places it never reached, so folders that merely looked empty must not be offered for deletion. Everything gathered so far is discarded. Use “Scan again” to restart.

Are files named like “.DS_Store 12-34-56” deleted too?
Variant names left by NAS or cloud sync are handled, but never on the strength of the name alone. The file's contents are checked, so only real Finder metadata is removed — a file you named yourself starting with .DS_Store is never touched.

What can the app see?
Only the folder you hand it. The app runs in the App Sandbox and cannot reach anything else.

Is any data sent anywhere?
No. The app performs no network communication at all. See the Privacy Policy.
